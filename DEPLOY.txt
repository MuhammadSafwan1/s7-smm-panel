═══════════════════════════════════════════════════════════
OPTION 3: VPS (Full Stack on Single Server)
═══════════════════════════════════════════════════════════

1. Get a VPS (DigitalOcean, Linode, AWS EC2)

2. Install Node.js:
   curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
   sudo apt-get install -y nodejs

3. Install PM2:
   sudo npm install -g pm2

4. Upload project files via FTP/Git

5. Install dependencies:
   cd backend && npm install
   cd frontend && npm install

6. Start backend:
   cd backend
   pm2 start src/server.js --name "msf-smm-backend"
   pm2 save
   pm2 startup

7. Build frontend:
   cd frontend
   npm run build

8. Serve frontend with nginx or serve it:
   npm install -g serve
   pm2 start "serve out -p 3000" --name "msf-smm-frontend"

9. Setup nginx reverse proxy (optional):
   - Backend: proxy_pass http://localhost:5000
   - Frontend: proxy_pass http://localhost:3000
